The headline win is not just a faster shader. It also changes the next bottleneck: layout, copies, and CPU fallbacks now matter because linear time shrank.

Dispatch Conditions

bool use_coopmat =
    !getenv("VK_DISABLE_COOPMAT") &&
    supports_cooperative_matrix() &&
    storage_type_of(out) == kBuffer &&
    M >= 64;

The coopmat export uses VulkanPartitioner({"storage_type_override": VkStorageType.BUFFER}), so activations and weights are buffers. Baseline used texture-backed weights for most linears.

Attention BMM Also Moved To Coopmat

The attention BMM kernels are small at seq=128, but they changed from matmul_vec_* to matmul_coopmat_float. That reduced attention matmul time from 14.5 ms to 0.93 ms.

matmul_coopmat.yaml

matmul_coopmat:
  parameter_names_with_default_values:
    DTYPE: float
    PRECISION: highp
  generate_variant_forall:
    DTYPE:
      - VALUE: float
      - VALUE: half
  shader_variants:
    - NAME: matmul_coopmat

matmul_coopmat.glsl

// Computes: D = A * B
// fp16 x fp16 -> fp32 MMA when input dtype is half.
// Same 64x64x32 tile shape as linear_coopmat.

coopMatLoad(matA[i], Ash, ...);
coopMatLoad(matB, Bsh, ...);
result[i][j] = coopMatMulAdd(matA[i], matB, result[i][j]);
