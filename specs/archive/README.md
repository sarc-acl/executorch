# Archived specs

Pre-M5 specs, moved here 2026-07-11. All of `001`-`013` were run on the
`rocky-ryzen` MiniPC (AMD Ryzen APU, RDNA3 iGPU) — the workstream's original
validation proxy before Samsung M5 EVT1 became the sole active target
(constitution Principle II, "Samsung M5 EVT1 Is the Only Active Target",
retired MiniPC 2026-07-05). Kept for historical reference only — do not
build or benchmark on this hardware going forward, and do not add new specs
here. Cross-references from later specs (e.g. `016`'s
`minipc-vs-m5evt1-comparison.md`) still cite these by their original
numbers; those citations remain valid since the numbering didn't change,
only the parent directory.
